Remote ONU — Web Browser

Rule dst-nat MikroTik otomatis diarahkan ke IP pelanggan (to-ports 80). Router / modem pelanggan hanya bisa dibuka bila fitur remote-nya aktif di perangkat.

🌐 Buka

Import Data Pelanggan

Unduh template Excel, isi sheet Pelanggan, lalu unggah di sini. CSV UTF-8 juga diterima.

Judul kolom sudah berbahasa Indonesia: Nama (satu-satunya yang wajib), Tipe, Paket, Agen, Username PPPoE, Password PPPoE, Nomor WhatsApp, Email, Alamat, IP Address, MAC Address, Status, Tanggal Masuk, Hari Tagihan. Paket dan Agen diisi namanya, bukan nomor ID. Kode pelanggan dibuat otomatis oleh sistem, jadi kolom kode tidak ada di template dan tidak dibaca saat import.

Data hanya ditambahkan — baris yang sudah ada tidak diubah, dan pesan WhatsApp tidak dikirim saat import. Baris bermasalah dilaporkan per baris, tidak menggagalkan seluruh file.
